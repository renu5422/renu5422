## 📌 Featured Projects

### ⚖️ NyayaSetu AI — IPC↔BNS legal-transition platform

Full-stack AI system with **482 validated IPC→BNS mappings**. A LangGraph agent (extract → retrieve → validate → compose, with an audit trace), a scikit-learn TF-IDF ranking model, and an MCP server exposing 5 tools — all on a **deterministic rules engine kept as ground truth**, so the LLM composes but never hallucinates the mapping. **200+ tests**, GitHub Actions CI.

`FastAPI` `LangGraph` `scikit-learn` `MCP` `Next.js` `Pytest`

### 📚 CourseHub — AI-enhanced learning platform

Full-stack platform with course management, auth, RBAC, and Genkit-powered AI tutoring. Handles Firestore's eventual consistency as a first-class concern.

`Next.js` `Firebase` `Firestore` `Genkit`

### 📖 BiblioManager — smart bookstore system

Full e-commerce flow with a scikit-learn KNN recommender trained on a ratings dataset (not a hard-coded list) and a rule-based support chatbot.

`Python` `Streamlit` `SQLite` `scikit-learn`

### 🧪 Test frameworks

Playwright/Pytest E2E (POM, bot-detection debugging) · Java/Selenium/TestNG (enterprise POM framework)
